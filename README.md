# My First Streamlit App

A simple web application built using Python and Streamlit.

## About the Project
This app allows users to enter their name and displays a personalized welcome message.

## Features
- Simple and user-friendly interface.
- Name input field.
- Personalized welcome message.
- Interactive Streamlit application.

## Technologies Used
- Python
- Streamlit

## Installation

Install Streamlit:

pip install streamlit

## Run the Application

streamlit run "app(1).py"

## Requirements
- Python
- Streamlit
